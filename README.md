# REQM 출고 관리 프로그램 1.0.26

셀메이트·면세점 주문 파일을 자동 판별하고, Supabase 품목 DB와 대조하여 택배 출고용 엑셀을 생성하는 Windows 설치형 프로그램입니다.

## 주요 기능

- B2C/B2B 입력 양식 자동 판별
- 품목명·품목코드 매칭과 유사/미등록 품목 표시 및 수동 수정
- 합포장과 실제 중복 출고 구분
- 관리자 전용 품목 DB 관리
- 판매처별 출고 품목의 이카운트 창고이동

## 이카운트 창고이동

1. 관리자 계정으로 로그인하고 출고 파일을 분석합니다.
2. `이카운트 창고이동`에서 판매처와 이동 창고를 선택합니다.
3. 정확·별칭·수동확정된 품목의 집계 수량을 확인합니다.
4. API 인증키를 입력하고 두 번의 실행 확인 후 전송합니다.

`API 인증현황`에서 최초 발급받은 테스트 키는 `테스트용 인증키 사용 (sboapi)`을 선택합니다. 검증 완료 후 발급받은 실제 운영 키는 선택을 해제하고 `oapi`를 사용합니다.

API 인증키는 소스나 `config.json`에 저장하지 않습니다. 사용자가 `키 저장`을 누른 경우에만 Windows DPAPI로 암호화하여 현재 Windows 사용자 전용 로컬 저장소에 보관합니다.

회사코드 `304293`과 ZONE `AB`는 고정됩니다. `사용자 불러오기 / 관리` 팝업에서 이카운트 사용자 ID와 담당자코드를 등록하면 다음 창고이동부터 선택하여 자동 입력할 수 있습니다.

창고이동 화면은 현재 출고 파일의 전체 판매처 주문을 집계하며, 판매처 이름은 적요에 자동으로 추가됩니다.

## 실행 준비

1. `config.example.json`을 `config.json`으로 복사합니다.
2. Supabase `publishable` 또는 기존 `anon` 키를 입력합니다.
3. Python 3.11 이상에서 `pip install -r requirements.txt`를 실행합니다.
4. `python main.py`로 실행합니다.

Supabase 비밀번호와 `service_role` 키는 GitHub에 커밋하지 마세요.

## 판매전표 반자동화 테스트 앱

`ecount_sales_app.py`는 스마트스토어 원본 주문을 품목/세트 DB와 매칭해 이카운트 판매전표 Excel을 생성합니다.

1. `python ecount_sales_app.py`로 실행합니다.
2. 필요하면 Supabase 이메일과 비밀번호로 최신 기준 DB를 불러옵니다. 비밀번호는 저장하지 않습니다.
3. 스마트스토어 원본 Excel, 주문 대상일, 전표 일자를 선택합니다.
4. `분석 및 자동 매칭`을 누르고 `확인 필요` 탭의 예외를 검토합니다.
5. 자동 변환 결과에서 수량·단가·창고를 수정한 뒤 `이카운트 Excel 저장`을 누릅니다.

기본값은 담당자 `00109`, 출하창고 `300`이며 QM4100은 `100` 본사창고로 자동 전환됩니다. 세트의 쿠폰·포인트 차액은 첫 번째 구성품인 본품에 반영하고 옵션품목 단가는 유지합니다.

상품금액은 스마트스토어의 `최종 상품별 총 주문금액`을 기준으로 하며, 배송비는 배송비 묶음번호별 실제 부담액을 한 번만 계산합니다. 확인 필요 항목이나 1원 이상의 금액 차이가 남아 있으면 전표 저장이 차단됩니다. 배송비 할인·제주/도서 추가배송비가 있는 묶음은 `배송비 검수` 탭에서 주황색으로 표시됩니다.
